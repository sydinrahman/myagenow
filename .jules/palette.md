## 2026-09-17 - WCAG Label-in-Name & High-Contrast Focus Indicator Micro-UX Pattern
**Learning:** Adding explicit `:focus-visible` outline rings (`outline: 2px solid var(--primary); outline-offset: 2px;`) to interactive text buttons (`.reset-button`, `.inline-action`) ensures clear keyboard navigation indicators without overriding default hover/active backgrounds. When providing tooltips or ARIA attributes on buttons with visible text, avoiding conflicting `aria-label` overrides ensures strict adherence to WCAG 2.5.3 (Label in Name) so speech-recognition engines can activate controls using their visible label text.
**Action:** Always test `:focus-visible` ring visibility during keyboard tabbing, and rely on `title` tooltips or inner button text instead of overriding `aria-label` when visible text is already concise and accurate.
